# GitThul 1.2.4

GitThul™ 1.2.4 delimita mejor los cambios al resolver conflictos, para que las
partes idénticas sigan siendo visibles aunque las versiones mezclen finales de
línea de Windows y Linux.

Un archivo pequeño con LF y CRLF podía aparecer como un borrado y un agregado
completos. El resolutor ahora alinea su contenido y conserva los terminadores
originales de las partes incorporadas y de las líneas elegidas.

## Mejoras y correcciones

- Las partes comunes se incorporan una sola vez, también cuando ambas ramas
  crearon el archivo por separado o añadieron el mismo texto dentro de cambios
  distintos. Las líneas repetidas y la ausencia de salto final ya no generan
  el conflicto adicional detectado durante la revisión.
- **Cancelar** y alternar entre archivos conservan las decisiones, el texto
  escrito y el bloque activo durante la sesión. Si cambian las versiones del
  conflicto o confirmas otra codificación, se descartan las decisiones anteriores.
- Los controles de bloque anterior y siguiente llegan también a bloques fuera
  de la pantalla.
- Al conservar una versión completa, la aplicación espera a que termine la
  escritura y muestra los errores para poder reintentar. La versión elegida
  conserva su tipo y modo registrados en Git.

## Compatibilidad y validación

Cambiar el terminador y el contenido de una misma línea puede seguir requiriendo
una decisión. Los enlaces simbólicos se resuelven eligiendo una versión completa;
los submódulos se resuelven desde la terminal y después se marcan como resueltos.
Los borradores del resolutor no sobreviven al cierre de la aplicación.

Pasaron las comprobaciones locales de tipos, lint, formato y compilación, junto
con 3.159 pruebas de frontend y 574 pruebas nativas en Linux. El flujo de liberación
verifica y construye los paquetes de Linux x64, Windows x64 y macOS Intel y Apple
Silicon. No se ha realizado una comprobación manual del resolutor en Windows ni
de la instalación en Windows o macOS para esta versión.

Windows sigue sin certificado comercial. macOS utiliza firma ad hoc, sin
notarización. Consulta los pasos y avisos de la guía de instalación.

## English summary

GitThul™ 1.2.4 keeps shared text visible when resolving conflicts with mixed LF
and CRLF line endings, while preserving the original endings of the selected
lines. It also retains shared sections in files created on both branches and
fixes an extra conflict involving repeated lines without a final newline.

Canceling or switching files preserves decisions and edits for the current
session. Block navigation reaches offscreen conflicts, and whole-file resolution
waits for the write, reports failures and preserves the selected Git file mode.
Symbolic links use whole-file selection; submodule conflicts require the terminal.

Local Linux checks, 3,159 frontend tests and 574 native tests passed. The release
pipeline checks and builds all four desktop targets. Manual verification of the
resolver on Windows and installation on Windows or macOS has not been performed
for this version. Windows installers have no commercial signing certificate;
macOS uses ad hoc signing without notarization.
