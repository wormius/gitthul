# GitThul 1.1.2

GitThul™ 1.1.2 hace más claras las diferencias que pueden pasar inadvertidas al
comparar archivos: permisos de ejecución, finales de línea, codificación, BOM,
representación Unicode, caracteres invisibles y renombrados.

Conserva las funciones de [1.1.1](https://github.com/wormius/gitthul/releases/tag/v1.1.1).
El código propio se distribuye bajo MIT.

## Visor de diferencias

- Los cambios de ejecución y de tipo de archivo muestran los modos anterior y
  nuevo, incluso cuando el diff no contiene líneas añadidas o eliminadas.
- El aviso de finales de línea distingue `CRLF`, `LF` y finales mixtos. Las
  conversiones que Git ya normaliza con atributos o configuración no aparecen
  como cambios pendientes.
- Los avisos de codificación, marca BOM, representación Unicode y caracteres
  invisibles explican esas diferencias. Los caracteres invisibles incluyen su
  punto de código y las cantidades anterior y nueva.
- Los renombrados y las copias muestran las dos rutas e indican si también
  cambió el contenido. Los avisos se mantienen breves y se desplazan cuando son
  numerosos para conservar espacio para el editor.
- Los espacios modificados se representan con `␣`; los tabuladores llevan una
  flecha cuyo ancho corresponde al espacio que ocupan hasta la siguiente parada
  de tabulación. Estas marcas conservan el texto original al copiar o preparar.
- El salto final se representa directamente en la numeración de cada lado, sin
  aviso adicional. La fila vacía del editor no se ofrece como una línea
  inexistente para preparar en Git.
- Al ver un enlace simbólico completo, el visor muestra el destino textual que
  Git guarda, sin seguir el enlace para leer otro archivo.

Estas mejoras se aplican al árbol de trabajo, Staging y los diffs históricos.
Los parches conservan sus bytes originales para preparar y descartar cambios.
La detección de codificación sin BOM sigue siendo una estimación; puedes usar
el selector de codificación para reinterpretar el archivo.

Consulta la [guía de diff e historial](https://github.com/wormius/gitthul/blob/v1.1.2/docs/diff-historial.md).

## Validación e instalación

La validación automatizada comprende frontend y Rust en Linux x64, Windows x64
y macOS Intel/Apple Silicon, con repositorios Git temporales para comprobar
permisos, enlaces, conversiones de texto y conservación de los bytes al preparar
y retirar cambios. La interfaz se revisó en navegador con temas claros y oscuros,
variantes, fuentes y tamaños de texto. La instalación y revisión manual de esta
versión en Windows y macOS siguen pendientes.

Los instaladores de Windows no tienen certificado de firma comercial. Las
aplicaciones de macOS tienen firma ad hoc y no están notarizadas por Apple.
`SHA256SUMS.txt` permite comprobar las descargas. Los avisos de las bibliotecas
del sistema incorporadas al AppImage se adjuntan en `linux-x64-system-notices.tar.gz`.

Consulta la [guía de instalación y dependencias](https://github.com/wormius/gitthul/blob/v1.1.2/docs/instalacion.md)
para instalar el paquete correspondiente a tu sistema.
