# GitThul 1.0.0

Primera versión pública de GitThul™, un cliente gráfico de Git de escritorio,
multiplataforma y libre. El código propio se distribuye bajo MIT.

## Funciones incluidas

- Biblioteca de repositorios, favoritos, recientes y Espacios.
- Grafo e historial, ramas, tags, stashes y worktrees.
- Diff, stage, unstage, descarte, commits y amend.
- Checkout, merge, rebase, cherry-pick, revert, reset, reflog y operaciones remotas.
- Resolución de conflictos y terminal integrada con sesiones y paneles divididos.
- Deshacer y rehacer durante la sesión; puntos de recuperación persistentes con
  vista previa, respaldo antes de restaurar, exportación y limpieza configurable.
- Perfiles Git, accesos con secretos en el llavero del sistema y registros de diagnóstico.
- Siete temas, tres variantes, tres densidades, fuentes locales y cinco idiomas:
  español de México, español de España, inglés, alemán y francés.

## Descargas e instalación

Los archivos adjuntos identifican su sistema y arquitectura:

| Sistema | Arquitectura          | Paquetes                          |
| ------- | --------------------- | --------------------------------- |
| Linux   | x64                   | `.deb`, `.rpm`, `.AppImage`       |
| Windows | x64                   | instalador `.exe` (NSIS), `.msi`  |
| macOS   | Apple Silicon (ARM64) | `.dmg` con `aarch64` en el nombre |
| macOS   | Intel (x64)           | `.dmg` con `x64` en el nombre     |

Necesitas Git instalado y disponible en el sistema. Para generar llaves SSH
desde GitThul también necesitas OpenSSH. Consulta la
[guía de instalación](https://github.com/wormius/gitthul/blob/v1.0.0/docs/instalacion.md).

`SHA256SUMS.txt` contiene las sumas SHA-256 de los paquetes. Permite comprobar
que la descarga coincide con el archivo publicado; no sustituye una firma digital.

Los instaladores de Windows no tienen certificado de firma comercial. Las
aplicaciones de macOS tienen firma ad hoc y no están notarizadas por Apple.
El sistema puede mostrar avisos o impedir su apertura según su política de seguridad.

## Alcance de esta versión

La aplicación no incluye telemetría ni una función de IA. La consulta de novedades
permanece desactivada; puedes revisar las versiones en
[GitHub Releases](https://github.com/wormius/gitthul/releases).

Deshacer y los puntos de recuperación cubren estados locales recuperables del
repositorio. No revierten publicaciones remotas ni efectos de comandos fuera
del repositorio, y no sustituyen un respaldo completo. Los límites de limpieza
son blandos: los puntos activos y las operaciones pendientes permanecen protegidos.

Siguen pendientes mover y reparar worktrees, completar la administración de
identidades y firmas GPG/SSH, y capacidades como submódulos, Git LFS, bisect y blame.

La numeración `1.0.0` identifica esta primera entrega; no implica que todas las
capacidades futuras de Git estén implementadas. Los avisos de terceros se incluyen
en los paquetes. El archivo `linux-x64-system-notices.tar.gz` adjunto documenta
las bibliotecas del sistema incorporadas al AppImage y la procedencia de sus avisos.
