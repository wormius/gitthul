# GitThul 1.0.1

Esta actualización de GitThul™ corrige las ventanas de consola que aparecían
brevemente en Windows durante operaciones internas, como abrir un repositorio
o consultar su estado. También corrige el directorio inicial de la terminal
integrada cuando se utiliza CMD con una ruta local de Windows.

Conserva las funciones de la [primera entrega pública, 1.0.0](https://github.com/wormius/gitthul/releases/tag/v1.0.0).
El código propio se distribuye bajo MIT.

## Correcciones en Windows

- Las consultas y operaciones internas de Git, SSH y sus auxiliares se ejecutan
  sin crear una ventana de consola. La terminal integrada conserva su shell
  interactivo dentro de GitThul.
- CMD recibe una ruta local compatible al abrir la terminal en el repositorio.
  Se evita que interprete el prefijo de una ruta canónica, como `\\?\C:\`, como
  una ruta UNC y termine en `C:\Windows`. La adaptación se aplica únicamente
  si ambas formas de la ruta identifican el mismo directorio.

CMD conserva su limitación para utilizar rutas UNC de red como directorio
actual. Esta actualización no modifica la ubicación del repositorio ni los
puntos de recuperación.

La corrección incorpora una prueba automatizada específica de Windows para
comprobar que los procesos internos no reciben una consola, además de pruebas
del directorio inicial del shell. Los paquetes se publican después de superar
las comprobaciones automatizadas de Linux, Windows y macOS.
**La comprobación visual y manual de estas correcciones en Windows sigue
pendiente.**

## Errores al crear commits

Si Git rechaza un commit por falta de nombre o correo, GitThul conserva ese
error y permite corregir la identidad. Se evita que aparezca un error genérico
de comunicación cuando Git termina antes de leer el mensaje del commit.

## Descargas e instalación

Los archivos adjuntos identifican su sistema y arquitectura:

| Sistema | Arquitectura          | Paquetes                          |
| ------- | --------------------- | --------------------------------- |
| Linux   | x64                   | `.deb`, `.rpm`, `.AppImage`       |
| Windows | x64                   | instalador `.exe` (NSIS), `.msi`  |
| macOS   | Apple Silicon (ARM64) | `.dmg` con `aarch64` en el nombre |
| macOS   | Intel (x64)           | `.dmg` con `x64` en el nombre     |

**macOS Intel:** instalación y funcionamiento siguen pendientes de validación
manual.

Necesitas Git instalado y disponible en el sistema. Para generar llaves SSH
desde GitThul también necesitas OpenSSH. Consulta la
[guía de instalación y dependencias](https://github.com/wormius/gitthul/blob/v1.0.1/docs/instalacion.md#dependencias).

Cierra GitThul y utiliza el paquete correspondiente a tu sistema para instalar
la actualización. La búsqueda de versiones en **Configuración → Actualizaciones**
ofrece un enlace a GitHub Releases; la descarga y la instalación se realizan
fuera de la aplicación.

`SHA256SUMS.txt` contiene las sumas SHA-256 de los paquetes. Permite comprobar
que la descarga coincide con el archivo publicado; no sustituye una firma digital.

Los instaladores de Windows no tienen certificado de firma comercial. Las
aplicaciones de macOS tienen firma ad hoc y no están notarizadas por Apple.
El sistema puede mostrar avisos o impedir su apertura según su política de seguridad.
