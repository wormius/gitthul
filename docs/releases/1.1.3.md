# GitThul 1.1.3

GitThul™ 1.1.3 corrige el error que indicaba que la carpeta del repositorio había
desaparecido al intentar ignorar un archivo del WIP. La acción ahora escribe la
regla correspondiente en el `.gitignore` del repositorio real.

Conserva las funciones de [1.1.2](https://github.com/wormius/gitthul/releases/tag/v1.1.2).
El código propio se distribuye bajo MIT.

## Ignorar archivos desde GitWorking

- **Ignorar** permite añadir una regla para el archivo, su extensión o su
  carpeta. `.gitignore` queda pendiente para que revises y prepares el cambio.
- **Ignorar y dejar de seguir** también retira del índice los archivos que
  coinciden con la regla y conserva sus copias locales. Si ya estaban en un
  commit, sus eliminaciones quedan preparadas para el siguiente.
- Los nombres con espacios o caracteres como `*`, `[` o `!` se tratan como
  rutas literales. La opción de ignorar una extensión conserva su alcance sobre
  los archivos y carpetas que coinciden con ella.
- Ambas acciones admiten **Deshacer** y **Rehacer** durante la sesión, incluida
  la recuperación de `.gitignore` y del índice del worktree.

## Arranque y ajustes

- La aplicación de escritorio utiliza las operaciones nativas de Git en todo
  su adaptador. El simulador y los datos de ejemplo quedan limitados al
  desarrollo y las pruebas, fuera de los paquetes de producción.
- Si el entorno de escritorio no está disponible al arrancar, aparece un aviso
  traducido que permite identificar el problema.
- Si falla la lectura de los ajustes, el registro conserva el error original y
  la aplicación carga una configuración segura, con los respaldos automáticos y
  la limpieza automática de recuperación desactivados.

## Validación e instalación

La validación local en Linux x64 comprende 2,871 pruebas de frontend y 517 de
Rust aprobadas; seis pruebas de Rust quedaron excluidas de la ejecución. También
se completó la compilación nativa de Linux sin generar instaladores. Estas
comprobaciones no incluyen la instalación manual en Windows o macOS.

Los instaladores de Windows no tienen certificado de firma comercial. Las
aplicaciones de macOS tienen firma ad hoc y no están notarizadas por Apple.
`SHA256SUMS.txt` permite comprobar las descargas. Los avisos de las bibliotecas
del sistema incorporadas al AppImage se adjuntan en `linux-x64-system-notices.tar.gz`.

## English summary

GitThul™ 1.1.3 fixes the misleading repository-folder error when ignoring a WIP
file. Ignore rules now update the real repository's `.gitignore`, which remains
unstaged for review. Ignoring and untracking preserves local files, and both
actions support session Undo and Redo.

Desktop operations use native Git throughout. Production packages exclude the
simulator and sample data, startup failures show a translated message, and a
settings-read failure preserves its diagnostic while disabling automatic
backups and recovery cleanup in the safe configuration.

Local Linux validation includes frontend and Rust tests and a native build.
Windows and macOS installation was not manually checked.
[Release notes and packages](https://github.com/wormius/gitthul/releases/tag/v1.1.3).
