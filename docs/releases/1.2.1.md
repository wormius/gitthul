# GitThul 1.2.1

GitThul™ 1.2.1 actualiza la biblioteca Brotli incluida en el AppImage de Linux x64
para corregir **CVE-2026-111497**. También actualiza Node.js, utilizado para
desarrollar, comprobar y compilar el proyecto.

## Corrección del AppImage

El AppImage 1.2.0 incluía Google Brotli 1.0.9, dentro del rango afectado por una
escritura fuera de límites al descomprimir datos Brotli manipulados. Este parche
incorpora **Brotli 1.0.10**, con la corrección oficial. La revisión confirma la
presencia de la biblioteca afectada en el paquete anterior; no demuestra una
explotación contra GitThul.

El empaquetado obtiene la fuente oficial, verifica su SHA-256 y comprueba que las
bibliotecas finales coinciden exactamente con las construidas. El AppImage incluye
su licencia y un manifiesto de procedencia. Estas comprobaciones también rechazan
copias adicionales que pudieran conservar una versión anterior.

La corrección requiere utilizar el nuevo AppImage: actualizar Node.js en el
equipo no reemplaza las bibliotecas incluidas en un AppImage ya descargado.
Consulta el [aviso oficial de Brotli](https://github.com/google/brotli/releases/tag/v1.0.10).

## Entorno de desarrollo y compilación

El proyecto y CI pasan a **Node.js 24.22.1**, que incluye las correcciones de
seguridad de octubre. Quienes compilan desde el código deben actualizar su
entorno antes de instalar las dependencias. La aplicación instalada utiliza
Tauri y Rust y funciona sin instalar Node.js.

## Lectura de respaldos

La lectura del catálogo de respaldos agrupa el acceso al archivo para evitar
operaciones de disco excesivas con manifiestos grandes. Se mantienen las
comprobaciones de integridad y recuperación de los respaldos.

## Validación y compatibilidad

La validación previa de estos cambios se realizó sobre un candidato local que
todavía llevaba el número **1.2.0**, antes de preparar esta liberación:

- Pasaron las comprobaciones locales de tipos, lint, formato, compilación web,
  pruebas de frontend y Rust, y las siete pruebas de las guardas del AppImage.
- El AppImage se construyó íntegramente en Ubuntu 22.04 x64. Se verificaron
  Brotli 1.0.10, los bytes finales de sus bibliotecas y el requisito máximo
  GLIBC 2.35 de los 183 archivos ELF del contenido.
- En Ubuntu 24.04 x64 se comprobó el arranque nativo y la lectura de referencias
  e historial de un repositorio Git real, con pantalla virtual y renderizado
  por software. También se comprobó el arranque en Ubuntu 26.04 x64.

Estas pruebas corresponden al candidato local del cambio y no son comprobaciones
de instalación de los paquetes oficiales 1.2.1. La revisión nativa descrita se
limita a Linux x64; no incluye pruebas nativas ni de instalación en Windows o
macOS.

DEB y RPM siguen utilizando las bibliotecas de la distribución; mantén actualizado
el sistema. El cambio del AppImage no sustituye bibliotecas de otros formatos ni
certifica el estado de los componentes web de Windows o macOS. Los instaladores
de Windows siguen sin certificado comercial y macOS utiliza firma ad hoc, sin
notarización. El código propio se distribuye bajo MIT.

## Instalación y ayuda

Para actualizar, descarga el paquete 1.2.1 correspondiente a tu sistema. Si
utilizas AppImage, reemplaza el archivo anterior y comprueba su SHA-256 con el
manifiesto de la release.

- [Release 1.2.1 y paquetes](https://github.com/wormius/gitthul/releases/tag/v1.2.1).
- [Instalación y dependencias](https://github.com/wormius/gitthul/blob/v1.2.1/docs/instalacion.md).

## English summary

GitThul™ 1.2.1 updates the Linux x64 AppImage to Google Brotli 1.0.10, fixing
**CVE-2026-111497**. Packaging verifies the official source checksum and the exact
library bytes included in the AppImage. Development and CI move to Node.js
24.22.1; installed GitThul does not require Node.js. Updating Node.js does not
replace Brotli inside an older AppImage.

Backup catalog reads now use buffered file access to avoid excessive disk
operations for large manifests, while retaining integrity and recovery checks.

Local automated checks, an Ubuntu 22.04 build, native checks with a real Git
repository on Ubuntu 24.04, and an Ubuntu 26.04 startup check passed for a
pre-release candidate still numbered 1.2.0. These checks cover that local
candidate, not installation of the official 1.2.1 packages. The native checks
described here cover Linux x64 only. DEB/RPM use distribution libraries. Windows
installers have no commercial signing certificate; macOS uses ad hoc signing
without notarization.
