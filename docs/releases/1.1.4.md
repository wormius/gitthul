# GitThul 1.1.4

GitThul™ 1.1.4 permite recorrer los carriles que quedan ocultos en el grafo de
GitWorking y corrige las terminales que desaparecían al cerrar el panel inicial
después de dividirlo. También facilita la lectura de archivos históricos: los
archivos sin cambios se abren completos y el margen de números de línea conserva
su ancho al desplazarse.

## Recorrer el grafo de commits

- La columna **Grafo** tiene una barra horizontal compacta sobre su borde inferior.
  Permite llegar a los carriles ocultos sin mover las etiquetas de ramas, los
  mensajes ni las demás columnas. También admite gestos horizontales, Mayús + rueda
  y teclado.
- Los bordes serrados indican en qué lado queda contenido oculto. Cambian al
  desplazarse y desaparecen cuando todo el grafo cabe en la columna.
- Al ampliar la columna o cambiar su contenido, la posición se ajusta al espacio
  disponible. La rueda limita los saltos grandes y conserva los movimientos
  pequeños del trackpad.

## Terminales divididas

- Al cerrar la terminal inicial después de crear divisiones, incluidas las
  anidadas, las terminales restantes siguen visibles y conservan sus procesos,
  contenido y foco.
- Los paneles utilizan separadores simples y aprovechan el espacio que antes
  ocupaban sus bordes y esquinas. El acceso a GitWorking aparece primero entre
  los botones de cada terminal.
- El historial lateral muestra su barra vertical y mantiene alineadas las
  cabeceras con las filas.

## Leer archivos y preparar commits

- En **Todos los archivos** del árbol de un commit, abrir un archivo que no cambió
  muestra directamente su contenido en esa revisión. Al abrir después un archivo
  modificado, vuelven los controles de comparación y tus ajustes anteriores.
- El margen de números de línea reserva desde el principio el ancho necesario
  para el archivo o diff completo. Ya no desplaza el código al pasar por decenas,
  centenas o millares. En archivos cortos, su fondo y separador llegan hasta la
  parte inferior del visor.
- Los filtros reservan espacio para el contador y el botón de limpiar, evitando
  que se superpongan con el texto. El selector de perfil alinea el nombre junto
  al avatar.
- La carga inicial de GitWorking muestra una barra de progreso mientras se
  consultan los datos del repositorio y la primera página del historial.
- Los separadores entre los paneles de GitWorking, la barra inferior y el mensaje
  de commit se muestran como una sola línea.

## Validación y compatibilidad

La validación local en Linux x64 completó 2,906 pruebas de frontend y 517 de
Rust aprobadas; seis pruebas de Rust quedaron excluidas de la ejecución. También
pasaron formato, análisis estático y compilaciones web y nativa de Linux. La
compilación nativa local no generó instaladores.

Las regresiones cubren las terminales divididas, el desplazamiento y los límites
del grafo, el margen de números de línea y la lectura de archivos sin cambios.
La revisión visual se realizó en navegador con datos simulados; esa comprobación
no sustituye la interfaz nativa ni la instalación de los paquetes. No se ha
comprobado manualmente la instalación de esta versión en Windows o macOS.

Los instaladores de Windows no tienen certificado de firma comercial. Las
aplicaciones de macOS tienen firma ad hoc y no están notarizadas por Apple.
`SHA256SUMS.txt` permite comprobar las descargas. Los avisos de las bibliotecas
del sistema incorporadas al AppImage se adjuntan en `linux-x64-system-notices.tar.gz`.
El código propio se distribuye bajo MIT.

## English summary

GitThul™ 1.1.4 adds horizontal navigation within GitWorking's graph column. A
compact scrollbar reveals hidden lanes, and sawtooth edges show which side still
has hidden content. Resizing keeps the position within bounds, while wheel and
trackpad input allow finer movement.

Closing the original terminal after nested splits keeps the remaining terminals
visible with their running processes, output and focus. Unchanged files opened
from a commit's full tree show their contents at that revision without changing
your diff preferences. Line number gutters keep a stable width while scrolling
and fill the viewer for short files. Filters avoid overlapping text, GitWorking
shows initial loading progress, and panel separators use a single line.

Local Linux validation passed 2,906 frontend tests and 517 Rust tests, plus web
and native builds; six Rust tests were excluded. Browser visual checks used
simulated data. Native UI and Windows/macOS installation were not manually
checked for this version.
Windows installers have no commercial signing certificate; macOS applications
use ad hoc signing and are not notarized.
