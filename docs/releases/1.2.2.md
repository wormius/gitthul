# GitThul 1.2.2

GitThul™ 1.2.2 conserva la vista al redimensionar paneles, permite recuperar el
panel de detalles plegado y devuelve el foco al repositorio al cerrar una terminal.

## Correcciones

- Arrastrar un separador o ajustar su tamaño con el teclado mantiene abierto el
  diff y conserva la selección. El control de plegado tampoco cierra el diff.
- El panel derecho plegado deja una franja con una flecha para volver a abrirlo.
  En Cambios y Stage, la flecha de plegado está antes de la papelera, en la misma
  fila del filtro. Sus borradores y filtros se conservan al plegarlo. También se
  recupera una distribución inicial utilizable si se había guardado una proporción
  de tamaño inválida.
- Al cerrar la terminal activa, el foco vuelve a la pestaña abierta de su
  repositorio, independientemente del orden de las pestañas. Si no hay una
  coincidencia, vuelve al último repositorio enfocado que siga abierto; si no
  queda ninguno, vuelve a Repositorios. Cerrar una terminal de fondo conserva el foco.

## Optimizaciones

Las consultas de repositorio e identidad Git se ejecutan en segundo plano. El
registro de diagnóstico agrupa la escritura de cada entrada y los diffs de archivos
ya rastreados evitan una consulta redundante al índice. Estos cambios reducen
trabajo de disco y esperas en el despacho de la interfaz, sin modificar los
resultados de las consultas.

## Compatibilidad y límites

La terminal comprueba el repositorio de su panel activo antes de elegir el destino.
La detección automática de cambios de carpeta en la shell está disponible en Linux;
Windows y macOS usan el último directorio conocido por GitThul.

Los instaladores de Windows siguen sin certificado comercial. macOS utiliza firma
ad hoc, sin notarización. Consulta los pasos y avisos de la guía de instalación.

## Validación

En Linux pasaron las comprobaciones locales de tipos, lint, formato y compilación
web, las **3108 pruebas de frontend** y las **566 pruebas Rust activas**. Las
pruebas cubren el resize, la recuperación del panel, el foco al cerrar terminales,
las lecturas asíncronas, los diffs, los registros y las regresiones de Git y recuperación.
Las pruebas HTTP utilizan un servidor local de prueba.

La revisión en navegador con datos simulados comprobó los controles con ratón y
teclado, la flecha junto a la papelera, la conservación del diff y el retorno al
repositorio. Estas comprobaciones no incluyen pruebas manuales de la aplicación
nativa ni de los instaladores en Linux, Windows o macOS.

## English summary

GitThul™ 1.2.2 keeps the current diff and selection when resizing panels, leaves
a visible button to reopen the collapsed details panel, and restores repository
focus when closing a terminal. The matching open repository takes priority;
otherwise, focus returns to the most recently focused repository still open.
The staging panel toggle sits before the discard button, alongside the file filter.

Repository and Git identity reads run on background workers. Diagnostic entries
use buffered writes, and ordinary tracked-file diffs skip a redundant index query.

Local Linux checks passed, including 3108 frontend tests, 566 active Rust tests,
and browser checks with simulated data. These checks do not include manual native
application or installer testing on Linux, Windows or macOS. Automatic shell
directory tracking is available on Linux; Windows and macOS use the last directory
known to GitThul. Windows installers have no commercial signing certificate;
macOS uses ad hoc signing without notarization.
