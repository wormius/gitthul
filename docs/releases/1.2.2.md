# GitThul 1.2.2

GitThul™ 1.2.2 conserva la vista al redimensionar paneles, permite recuperar el
panel de detalles plegado y devuelve el foco al repositorio al cerrar una terminal.
Esta versión está en preparación; todavía no se ha publicado.

## Correcciones

- Arrastrar un separador o ajustar su tamaño con el teclado mantiene abierto el
  diff y conserva la selección. El control de plegado tampoco cierra el diff.
- El panel derecho plegado deja una franja con una flecha para volver a abrirlo.
  Sus borradores y filtros se conservan. También se recupera una distribución
  inicial utilizable si se había guardado una proporción de tamaño inválida.
- Al cerrar la terminal activa, el foco vuelve a la pestaña abierta de su
  repositorio, independientemente del orden de las pestañas. Si no hay una
  coincidencia, vuelve al último repositorio enfocado que siga abierto; si no
  queda ninguno, vuelve a Inicio. Cerrar una terminal de fondo conserva el foco.

La terminal comprueba el repositorio de su panel activo antes de elegir el
destino. La detección automática de cambios de carpeta en la shell está disponible
en Linux; Windows y macOS usan el último directorio conocido por GitThul.

## Optimizaciones

Las consultas de repositorio e identidad Git se ejecutan en segundo plano para
evitar que sus accesos a disco o procesos Git retengan el despacho de la interfaz.
El registro de diagnóstico agrupa la escritura de cada entrada, conservando su
contenido y la protección de datos sensibles. Los diffs normales de archivos ya
rastreados evitan una consulta redundante al índice.

## Validación

Las comprobaciones de tipos, lint, formato y compilación web finalizaron
correctamente. Las pruebas automatizadas cubren el resize, la recuperación del
panel y el foco al cerrar terminales, incluidas consultas de repositorio pendientes
y cambios de foco durante la espera. La revisión en navegador con datos simulados
comprobó los controles con ratón y teclado, el diff y el retorno al repositorio.

Las comprobaciones y pruebas del backend Rust en Linux verificaron las lecturas
asíncronas, los diffs y la persistencia del registro, junto con las regresiones de
Git y recuperación. Las pruebas HTTP usan un servidor local de prueba.

Todavía no se han probado estos cambios en la aplicación nativa ni en instaladores
de Linux, Windows o macOS. No se atribuyen resultados de rendimiento a esta versión.

## English summary

GitThul™ 1.2.2 keeps the current diff and selection when resizing panels, leaves
a visible button to reopen the collapsed details panel, and restores repository
focus when closing a terminal. The matching open repository takes priority;
otherwise, focus returns to the most recently focused repository still open.

Repository and Git identity reads run on background workers. Diagnostic entries
use buffered writes, and ordinary tracked-file diffs skip a redundant index query.

Automatic shell directory tracking is available on Linux; Windows and macOS use
the last directory known to GitThul. Automated frontend checks and browser checks
with simulated data passed. Native applications and installers have not yet been
tested for these changes. This version is in preparation and has not been published.
Rust backend checks and tests passed on Linux.
See [published releases](https://github.com/wormius/gitthul/releases).
