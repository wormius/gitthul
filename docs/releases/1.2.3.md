# GitThul 1.2.3

GitThul™ 1.2.3 corrige el bloqueo de los gestos de arrastrar y soltar dentro de
la aplicación en Windows.

El puntero podía mostrar el símbolo de operación prohibida incluso sobre un
destino válido. La ventana ahora permite que los eventos de arrastre lleguen a
la interfaz, para usar los gestos de archivos, referencias, repositorios y pestañas.
Los destinos que no admiten una operación siguen rechazándola.

## Compatibilidad y validación

La corrección se dirige a los arrastres internos de GitThul. No añade importación
de archivos o carpetas arrastrados desde el Explorador de Windows.

Pasaron las comprobaciones locales de tipos, lint, formato y compilación web en
Linux, junto con las pruebas automatizadas de frontend y Rust. La liberación
también pasa por la CI y la construcción de paquetes para Linux x64, Windows x64
y macOS Intel y Apple Silicon. Estas comprobaciones no sustituyen la prueba
manual del gesto en Windows, que no se ha realizado para esta versión.

Windows sigue sin certificado comercial. macOS utiliza firma ad hoc, sin
notarización. Consulta los pasos y avisos de la guía de instalación.

## Instalación y ayuda

Descarga e instala el paquete 1.2.3 correspondiente a tu sistema. La corrección
requiere el nuevo ejecutable. Si utilizas AppImage, reemplaza el archivo anterior
y comprueba su SHA-256 con el manifiesto de la release.

## English summary

GitThul™ 1.2.3 fixes blocked internal drag-and-drop gestures on Windows, where
the pointer could show a forbidden symbol even over a valid target. The window
now lets drag events reach the interface. Unsupported targets still reject drops;
this release does not add file or folder imports from Windows Explorer.

Local Linux checks and automated frontend and Rust tests passed. The release
pipeline also checks and builds packages for Linux x64, Windows x64, and both
macOS architectures. Manual verification of the gesture on Windows has not been
performed for this version. Windows installers have no commercial signing
certificate; macOS uses ad hoc signing without notarization.
