# Repositorios y alias

Puedes asignar un alias desde el menú contextual de un repositorio en las listas
o los espacios, o desde el menú contextual de su pestaña abierta. El alias aparece
en esas vistas y en la cabecera de GitWorking; se guarda para las siguientes
sesiones. Vacía el campo del alias para volver al nombre original.

También puedes hacer **doble clic sobre el nombre de una pestaña** para editar
el alias ahí mismo. Pulsa **Enter** o haz clic fuera para guardar, o **Escape**
para cancelar. Dejar el campo vacío recupera el nombre original. El cambio se
aplica a todas las pestañas del mismo repositorio, incluidas sus terminales.
Si no se puede guardar, el texto permanece en el campo para que lo reintentes.

El alias solo cambia cómo identificas el repositorio en GitThul. Su carpeta,
remotos e identidad Git se conservan. Puedes encontrarlo por su alias, nombre
original o ruta.

## Elegir un avatar

Abre **Cambiar avatar** en el menú contextual del repositorio para elegir una
ilustración y su color. El catálogo incluye 128 dibujos repartidos en Símbolos,
Animales, Plantas, Festividades y Abstractos, y también está disponible para los
perfiles. Puedes usar uno de los tonos del tema, un color personalizado o volver
a las iniciales.

La versión 1.2.0 redibuja los 85 avatares anteriores y añade 43. Las elecciones
guardadas conservan el mismo motivo y color; no necesitas volver a asignarlas.

## Seleccionar varios repositorios

En Repositorios, mantén **Ctrl** (Windows/Linux) o **Cmd** (macOS) mientras haces
clic para añadir o quitar repositorios de la selección. **Shift + clic** selecciona
un rango. Funciona en las listas y en las tarjetas de los espacios.

Con el foco en una lista o en las tarjetas, **Ctrl/Cmd + A** selecciona todos los
repositorios visibles. **Shift + flechas** extiende la selección y
**Ctrl/Cmd + Espacio** alterna el repositorio enfocado.

Abre el menú contextual sobre uno de los seleccionados y elige **Abrir** para
abrirlos en pestañas. También puedes pulsar Enter. Las pestañas que ya están
abiertas se reutilizan. Con el foco en la lista o en una tarjeta,
**Shift + F10** abre el menú contextual.

Elige **Olvidar** en el menú contextual para quitarlos de la lista de GitThul.
La confirmación muestra los nombres y rutas de todos los seleccionados. Sus
carpetas y el historial de Git se conservan. Cancelar mantiene los repositorios
en la biblioteca.

Si un repositorio aparece en varias secciones o espacios, se cuenta una sola vez.
Al filtrar, los repositorios que quedan ocultos dejan de estar seleccionados.
El menú contextual conserva el grupo cuando se abre sobre uno de sus miembros;
si se abre sobre otro repositorio, la acción se aplica a ese repositorio.

Para agregar el grupo a un espacio, arrastra cualquiera de los repositorios
seleccionados y suéltalo en el espacio de destino. Sus membresías anteriores se
conservan y los repositorios que ya pertenecen al destino no se duplican.
El arrastre indica cuántos repositorios lleva. Si arrastras uno que no está
seleccionado, se toma únicamente ese repositorio.

En el reparto Lista aparecen los espacios disponibles al comenzar el arrastre.
Puedes soltar el grupo en **Nuevo espacio**, escribir su nombre y crearlo con
todos los repositorios. Cancelar conserva los espacios actuales.

Para sacar un repositorio de un espacio, abre el menú contextual de su tarjeta
y elige **Quitar de [nombre del espacio]**. Desde las listas Recientes y Todos,
elige **Quitar de un espacio** y luego el espacio concreto.

Estas acciones también funcionan con selecciones múltiples: el menú indica los
repositorios afectados por cada espacio. Los repositorios siguen disponibles
en Todos, con sus pestañas, carpetas e historial de Git conservados. Puedes
volver a agregarlos a un espacio mediante el arrastre. Si un repositorio pertenece
a varios espacios, quítalo de cada uno por separado.

Si alguna apertura o acción de Olvidar falla, las demás se completan. Al volver a
Repositorios puedes revisar el error de cada entrada fallida y reintentarlas.
