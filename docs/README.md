# Guías de uso de GitThul

Estas guías explican cómo utilizar GitThul y qué efectos tienen sus acciones.

- [Instalación y acceso desde el escritorio](instalacion.md): preparar las
  dependencias, comprobar Git y SSH, instalar el paquete de tu sistema e integrar
  un AppImage en Linux.
- [Atajos de teclado](atajos.md): navegación, acciones habituales y edición de
  texto.
- [Búsqueda global](busqueda-global.md): encontrar repositorios, commits,
  archivos, opciones y acciones.
- [Diff e historial de un archivo](diff-historial.md): revisar una comparación
  y consultar otras versiones desde el mismo visor.
- [Modificar el último commit](amend.md): cambiar su mensaje, incorporar staging
  y revisar el historial publicado.
- [Perfiles y acceso a remotos](perfiles-y-accesos.md): identidad de commits,
  credenciales HTTPS y llaves SSH.
- [Terminal integrada](terminal.md): shell, copiar, pegar y buscar en la salida.
- [Recuperación persistente](recuperacion-persistente.md): revisar, restaurar y
  conservar puntos de recuperación.
- [Registros y diagnóstico](logs-diagnostico.md): consultar registros y reportar
  un problema.
- [Versión instalada y actualizaciones](versiones-publicadas.md): buscar
  versiones estables y recibir avisos de nuevas publicaciones.
