# Versión instalada y actualizaciones

Abre **Configuración → Actualizaciones** para consultar la versión instalada
de GitThul.

La consulta de nuevas versiones todavía no está configurada. **Buscar ahora**,
la consulta al iniciar y la selección de canal permanecen desactivados. Aunque
una preferencia anterior haya dejado activada la consulta al iniciar, GitThul
no realiza esa consulta ni muestra avisos de descarga.

La sección indica que la consulta no está disponible; ese estado no confirma
que tengas la versión más reciente. GitThul no descarga ni instala
actualizaciones automáticamente.

Si recibes un paquete nuevo para tu sistema, sigue la guía de
[instalación](instalacion.md). Las operaciones Git que eliges, como clonar,
fetch, pull y push, siguen funcionando con normalidad.
